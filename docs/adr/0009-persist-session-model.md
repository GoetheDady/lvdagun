# 按会话选择并持久化模型

模型选择属于会话,而不是浏览器客户端或全局模型配置。用户选择会话模型时立即持久化,即使尚未发送消息也必须在刷新或重启后恢复;新会话从默认模型开始。候选项使用 Pi 当前所有已认证 Provider 的可用模型,切换复用 Pi 原生会话模型能力。这样输入区中的模型选择只影响当前会话后续的 Agent 运行,不会意外改变其他会话。

**Considered Options**:

- 修改全局模型配置:实现路径较短,但在一个会话输入区内操作却影响全部会话,作用域与界面位置不一致。
- 只在客户端临时保存:无需扩展服务端协议,但刷新、重启或换客户端后会静默丢失选择。
- 按会话持久化(选中):作用域清晰,多客户端观察同一会话时也能得到一致状态。

**Consequences**:

- 模型和思考等级只允许在会话空闲时修改;Agent 运行或上下文压缩期间禁用。
- 切换模型后,思考等级收敛到目标模型支持的等级。
- 模型列表按 Provider 分组,不展示缺少有效凭据的模型。
- Provider 凭据由 Pi 持久保存在 `~/.lvdagun/auth.json`;测试连接成功后写入,失败时不修改凭据。
- 恢复时若原会话模型已不可用,回退到默认可用模型并向客户端明确报告警告。
- 同一会话的模型和思考等级变更同步到所有客户端;并发修改以服务端最后成功写入为准。
