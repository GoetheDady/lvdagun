# 使用会话快照恢复断线对话

**Status**: accepted; transport defined by ADR-0013

客户端首次打开或重新连接会话时通过当前应用连接接收权威快照，快照包含产品当前分支完整历史、revision、活动内存草稿和会话运行状态。服务端先建立事件订阅，生成快照期间暂存新事件，随后按“快照、暂存事件、实时事件”发送；这样已有内容立即完整显示，新内容继续流式追加，且快照与续流之间不留缺口。

不为断线恢复持久化或补发传输事件日志。断线期间的工具输出帧和重试倒计时可以缺失，但产品快照会恢复已经提交的历史和仍在内存中的活动草稿；应用用较小的协议与状态成本换取用户可见结果正确。客户端建立新连接并重新订阅，暂不增加应用层心跳与自定义退避；服务重启后从产品历史恢复已提交内容，并把未结算 Agent 运行标记为已中断。
