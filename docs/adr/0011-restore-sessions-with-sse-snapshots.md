# 使用 SSE 会话快照恢复断线对话

客户端首次打开或重新连接会话时统一通过同一条 SSE 连接接收权威快照,快照包含当前分支完整历史、尚在生成的助手消息和会话运行状态。服务端先建立事件订阅,生成快照期间暂存新事件,随后按“快照、暂存事件、实时事件”发送;这样已有内容立即完整显示,新内容继续流式追加,且快照与续流之间不留缺口。

不为断线恢复持久化或补发事件日志。断线期间的工具输出帧和重试倒计时可以缺失,但快照会恢复可确定的当前工具运行和最终状态;本地应用用较小的协议与状态成本换取用户可见结果正确。浏览器负责原生重连,暂不增加心跳与自定义退避;服务重启后只恢复 Pi 已持久化的消息,不承诺恢复进程退出时尚未落盘的部分回复。
