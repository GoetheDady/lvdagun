# Triage Labels

技能使用五个规范化 triage 角色。本文件把这些角色映射到本仓 issue 跟踪器实际使用的标签字符串。

| 技能角色标签      | 本仓标签          | 含义(中文)                |
| ----------------- | ----------------- | ------------------------- |
| `needs-triage`    | `needs-triage`    | 待维护者评估              |
| `needs-info`      | `needs-info`      | 等待提问者补充信息        |
| `ready-for-agent` | `ready-for-agent` | 规格完整,可由 AI 代理接手 |
| `ready-for-human` | `ready-for-human` | 需要人工实现              |
| `wontfix`         | `wontfix`         | 不予处理                  |

技能提到某个角色时(如"打上 AFK-ready triage 标签"),使用上表对应的标签字符串。
